# SIH Platform - AYUSH Skill Development & Industry-Academia Connect

SIH Problem Statement 26044 (AYUSH ecosystem prototype)

A comprehensive full-stack web platform connecting Students, Faculty, Institutes/Colleges, and Industries to improve skill development, identify skill gaps, and connect academic skills with industry requirements. The bundled sample data demonstrates the **AYUSH ecosystem**: the six AYUSH systems, their academic programmes, career areas, skills, and the skill-gap → learning-recommendation → opportunity journey.

# Features

# -- Student Module
- Complete profile creation with academic and skill information
- Skill categorization and management
- Skill gap analysis against industry requirements
- Recommended skills and learning opportunities
- Browse and discover internship, job, and event opportunities

# -- Faculty Module
- Professional profile with expertise and skills
- Department information and subjects taught
- Student skill insights and trends
- Industry-required skills analysis
- Curriculum development recommendations

# -- Institute Module
- Aggregated analytics dashboard
- Students by branch and batch distribution
- Skill distribution and common skills analysis
- Career interest trends
- Participation metrics (internships, jobs, events)
- Visual charts and graphs

# -- Industry Module
- Company/industry profile management
- Post job, internship, event, and skill-program opportunities
- Specify required skills and eligibility criteria
- Talent market analytics
- Skill demand vs supply analysis
- High-demand low-supply skill identification

# -- Skill Gap Engine
- Calculate current skill strength
- Identify missing and weak skills
- Industry demand analysis
- Personalized skill recommendations
- Modular algorithm design (extensible to ML/AI)

# --> Tech Stack

- **Frontend**: HTML5 + CSS3 + Vanilla JavaScript
- **Backend**: Python + FastAPI
- **Database**: MySQL with SQLAlchemy ORM
- **Data Processing**: NumPy + Pandas
- **Visualization**: Matplotlib
- **API**: REST API with JavaScript fetch()

# Setup & Running

# Prerequisites
- Python 3.8 or higher
- pip (Python package installer)

# Windows Setup

1. **Install dependencies:**
```bash
pip install -r requirements.txt
```

2. **Run the application:**
```bash
uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000
```

3. **Open in browser:**
```
http://localhost:8000
```

# API Endpoints

## Authentication
- `POST /api/auth/login` - User login
- `POST /api/auth/signup` - User registration
- `GET /api/auth/me/{user_id}` - Get current user

## Student Profile
- `POST /api/student/profile/{user_id}` - Create profile
- `GET /api/student/profile/{user_id}` - Get profile
- `PUT /api/student/profile/{user_id}` - Update profile

## Faculty Profile
- `POST /api/faculty/profile/{user_id}` - Create profile
- `GET /api/faculty/profile/{user_id}` - Get profile
- `PUT /api/faculty/profile/{user_id}` - Update profile

## Industry Profile
- `POST /api/industry/profile/{user_id}` - Create profile
- `GET /api/industry/profile/{user_id}` - Get profile
- `PUT /api/industry/profile/{user_id}` - Update profile

## Opportunities
- `POST /api/opportunities` - Create opportunity

- `GET /api/opportunities/{id}` - Get single opportunity
- `PUT /api/opportunities/{id}` - Update opportunity
- `DELETE /api/opportunities/{id}` - Delete opportunity

## Analytics
- `GET /api/analytics/student/skill-gap/{user_id}` - Skill gap analysis
- `GET /api/analytics/institute/analytics/{institute_id}` - Institute analytics
- `GET /api/analytics/institute/charts/{institute_id}` - Institute charts
- `GET /api/analytics/industry/demand-analysis` - Industry demand analysis
- `GET /api/analytics/skill-rankings` - Skill demand rankings

# Key Implementation Details

## Skill Gap Algorithm
The skill gap engine (`backend/services/skill_analysis.py`) calculates:
1. Current skill levels (default: 3/5 for skills in profile)
2. Industry demand scores (based on skill frequency in opportunities)
3. Gap = Demand - Current
4. Recommendations sorted by priority

## Analytics & Charts
The analytics service (`backend/services/analytics.py`) generates:
- Bar charts for distributions
- Pie/donut charts for proportions
- Horizontal bar charts for rankings
- Grouped bar charts for comparisons

Charts are generated as base64-encoded PNG images and served through API.

## Data Models
- **User**: Base authentication model
- **StudentProfile**: Extended student information
- **FacultyProfile**: Extended faculty information
- **IndustryProfile**: Company/industry details
- **Opportunity**: Job/internship/event postings
- **Institute**: Institute/college information

# Customization

## Adding Skills
Edit `backend/services/skill_analysis.py` to add new skills to the AYUSH-oriented `skill_categories` dictionary. Keep the spelling identical to the skill names used in `backend/seed.py` so skill-gap analysis continues to match student skills against opportunity requirements.

## Adding New Institutes
The demo dataset ships with fictional `Demo ...` AYUSH institutes. Add your own through the database or signup flow.

## Extending Analytics
The analytics service is modular. Add new chart types or calculations as needed.

# Troubleshooting

## Port Already in Use
```bash
# Kill process on port 8000 (Windows)
netstat -ano | findstr :8000
taskkill /PID <PID> /F
```

# Database Issues
Ensure MySQL is running and `DATABASE_URL` in `.env` points to your MySQL server. For default local dev:

```
DATABASE_URL=mysql+pymysql://<Username>:<Password>@localhost:<Port>/<Database>
```

The backend creates tables automatically on startup. If you change credentials, update `.env` and restart.

# Static Files Not Loading
Ensure the `frontend/` directory structure is correct and the paths in `main.py` match your setup.
